## Descripción de la actividad

En este taller se analiza la base de datos **TenderosFU03_Publica**, que contiene información sobre el uso de internet por parte de tenderos en distintos municipios y departamentos de Colombia, así como la base **TerriData_Dim2**, con información territorial complementaria. A partir de estas bases se realizan agrupaciones, filtros y cálculos de promedios y sumas para responder distintas preguntas planteadas en cada punto del taller.

Cada script en la carpeta `scripts/` corresponde a un punto específico del taller:

| Script | Descripción |
|---|---|
| `tarea 1.R` | Calcula el porcentaje promedio de uso de internet por municipio/departamento. |
| `tarea 2.R` | Calcula el porcentaje promedio de uso de internet según el tipo de actividad económica del tendero (actG1 a actG11). |
| `tarea 3.R` | Calcula el porcentaje promedio de uso de internet agrupado por municipio/departamento y tipo de actividad. |
| `tarea 4.R` | Procesa la base TerriData_Dim2 para obtener el dato numérico total por departamento. |
